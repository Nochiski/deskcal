# DeskCal

Windows용 가벼운 데스크톱 캘린더입니다. Google 캘린더와 iCloud 캘린더를 한 화면에 월별로 보여주고,
작업표시줄에는 뜨지 않고 트레이 아이콘으로만 동작합니다. 바탕화면 위젯처럼 붙이거나 배경화면 뒤(아이콘 뒤)로
보낼 수 있고, 일정 시각에 맞춰 Windows 알림을 띄웁니다. 일정 생성·수정·삭제도 됩니다.

## 설치

1. [Releases](https://github.com/Nochiski/deskcal/releases)에서 `DeskCal_x.y.z_x64-setup.exe`를 내려받아 실행합니다.
2. 서명되지 않은 앱이라 SmartScreen 경고가 뜰 수 있습니다. **추가 정보 → 실행**을 누르면 됩니다.
3. 설치가 끝나면 트레이(작업표시줄 오른쪽 아래 ^ 영역)에 DeskCal 아이콘이 생깁니다. 아이콘을 클릭하면 창이 열리고, 우클릭하면 메뉴가 나옵니다.

Windows 10/11 64비트에서 동작하며 별도 런타임 설치는 필요 없습니다.

## 계정 연결

앱을 열고 **설정(⚙) → 계정**에서 연결합니다. 여러 개를 동시에 연결할 수 있습니다.

| 방식 | 할 수 있는 것 | 준비물 |
| --- | --- | --- |
| **Google로 로그인** | 일정 보기 + 생성/수정/삭제, 알림 | Google 계정. 브라우저에서 로그인하고 권한을 허용하면 끝. 계정을 여러 개 추가할 수 있음 |
| **iCloud 연결** | 일정 보기 + 생성/수정/삭제, 알림 | Apple ID + [앱 암호](https://appleid.apple.com) (로그인 및 보안 → 앱 암호 → 생성). 일반 비밀번호는 안 됨 |
| **iCal 구독 (URL)** | 일정 보기만 | 아무 `.ics` / `webcal://` 주소. 예: Google 캘린더 설정의 "비공개 주소(iCal 형식)", 공휴일 캘린더 |

Google 로그인 시 "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → DeskCal(으)로 이동**을 누르세요.
이 앱은 서버 없이 PC에서만 동작하며 어떤 데이터도 수집하지 않습니다. 자세한 내용은 [PRIVACY.md](PRIVACY.md)에 있습니다.

## 사용법

- **월 이동**: 상단 ‹ › 또는 "오늘". 상단 바의 빈 영역을 끌면 창을 옮길 수 있습니다.
- **일정 추가**: 상단 "일정 추가" 버튼, 또는 날짜 칸을 더블클릭.
- **일정 수정/삭제**: 일정을 클릭 → 팝오버에서 수정/삭제. (iCal 구독과 iCloud 반복 일정은 읽기 전용)
- **캘린더 표시/알림**: 설정 → 캘린더에서 캘린더별로 표시 여부, 알림 여부, 색을 바꿉니다.
- **알림**: 설정 → 알림에서 기본 알림 시간, 종일 일정 알림 시각을 정합니다. 일정에 알림이 설정돼 있으면 그 값을 따릅니다.
- **창 모드** (트레이 메뉴 또는 설정 → 표시):
  - *일반 창* — 항상 열 수 있는 반투명 창. 작업표시줄에는 안 뜹니다.
  - *바탕화면 위젯* — 바탕화면 아이콘 위, 모든 창 아래에 고정. Win+D를 눌러도 남고 클릭할 수 있습니다.
  - *배경화면* — 바탕화면 아이콘 뒤에 표시. 보기 전용입니다.
- **종료**: 창을 닫아도 트레이에 남습니다. 완전히 끄려면 트레이 메뉴 → 종료.
- **시작 시 자동 실행**: 설정 → 표시.

## 데이터 위치

- 설정/캐시: `%APPDATA%\com.nochiski.deskcal\`
- 로그: `%LOCALAPPDATA%\com.nochiski.deskcal\logs\deskcal.log`
- 로그인 토큰/앱 암호: Windows 자격 증명 관리자 (`DeskCal` 항목)

계정 연결을 해제하면 해당 토큰과 캐시가 지워집니다. Google 권한은 <https://myaccount.google.com/permissions>에서도 취소할 수 있습니다.

## 알려진 제한

- 배경화면 모드에서는 Windows 아이콘 레이어가 입력을 받으므로 캘린더를 클릭할 수 없습니다.
- iCloud 반복 일정은 앱에서 수정할 수 없고(단일 일정만), 일정을 다른 캘린더로 옮기는 기능은 없습니다.
- iCal 구독은 읽기 전용이며, 반복 규칙은 DAILY/WEEKLY/MONTHLY/YEARLY의 기본 형태만 전개합니다.

소스에서 직접 빌드하려면 [docs/BUILDING.md](docs/BUILDING.md)를 보세요.
